# Главные выводы
1.Платформа .NET — кроссплатформенная среда. Один и тот же IL-код может выполняться на Windows, macOS и Linux благодаря CLR, которая через JIT-компиляцию превращает IL в машинный код конкретного процессора.
2.Целочисленное деление — важная особенность C#. Операция 10 / 3 для типа int даёт 3, а не 3.333.... Для получения дробного результата нужно явное приведение: (double)10 / 3.
3.Терминал — главный инструмент разработчика. Команды dotnet new, dotnet run, git add, git commit, git push выполняются из терминала и автоматизируют рутинные операции.

# Ответы на вопросы
1.WriteLine следующий вывод начнётся с новой строки, а после Write — продолжится на той же строке.
2.Компилятор выдаст ошибку: Cannot implicitly convert type 'double' to 'int'. Для корректного присваивания нужно явное приведение: int x = (int)3.14; — при этом дробная часть будет отброшена, и x станет равен 3.
3.компилятор выполняет целочисленное деление — дробная часть отбрасывается. Чтобы получить дробный результат, нужно, чтобы хотя бы один операнд был типа double:

double result = (double)10 / 3; // 3.333...


double result2 = 10.0 / 3;       // 3.333...

4.var — это неявная типизация: компилятор сам определяет тип переменной по присвоенному значению на этапе компиляции. Тип фиксируется один раз и больше не меняется.

В Python переменная может в любой момент изменить тип (динамическая типизация): x = 5; x = "строка" — это нормально. В C# с var такое невозможно

Unity — популярный игровой движок, на котором созданы такие игры, как Among Us, Genshin Impact, Hollow Knight; скриптинг ведётся на C#.
